# Changelog

- First release: `Handoff` core (QR pairing, AES-GCM end to end, WebRTC data channel with an encrypted client-event relay fallback), `authorizeHandoff` for auth routes, the `useHandoff` React hook and the `<hibira-handoff>` element in seven languages.
